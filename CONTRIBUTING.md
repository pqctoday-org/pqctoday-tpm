# How to contribute

PQC Today welcomes feedback. Tell us what works well and what doesn't:
errors, gaps, spec divergences, unclear explanations, ideas.
Please use **Issues** or **Discussions**.

**Code changes are made only by the maintainer.** We don't merge outside pull
requests. If you open one, we'll thank you and close it, and if the idea is
good we'll make the change ourselves.

By sending feedback, you agree that PQC Today, LLC may use it freely, in any
version of the project.

Fixes to the upstream code are best reported to
[libtpms](https://github.com/stefanberger/libtpms) and
[swtpm](https://github.com/stefanberger/swtpm) directly.
